# ASE242S3_T04 Frontend migrado a React + Vite

Proyecto migrado desde Angular a React, manteniendo una estructura similar al proyecto principal:

- `src/api`: conexión con backend y servicios HTTP.
- `src/types`: modelos TypeScript.
- `src/layouts`: Header, Footer y layout principal.
- `src/pages`: vistas principales y panel admin.
- `src/router`: rutas protegidas.
- `src/assets`: imágenes originales del proyecto Angoma.

## Ejecutar

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```
